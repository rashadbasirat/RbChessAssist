# Third-party software and assets

- **Stockfish 19** — GPL-3.0. Official upstream binary distribution, source, authors, and Copying.txt are included under `stockfish/` in the Windows package. https://github.com/official-stockfish/Stockfish/tree/sf_19
- **Shakmaty** — GPL-3.0-or-later. Chess rules, notation, and Polyglot position hashing. https://github.com/niklasf/shakmaty
- **Chess piece graphics** — Cburnett artwork supplied by python-chess, GPL-2.0-or-later, distributed here under GPL-3.0-or-later. Twelve PNG/SVG assets were rendered from python-chess's `chess.svg.piece`. https://github.com/niklasf/python-chess/blob/master/chess/svg.py
- **egui / eframe / egui_extras** — MIT OR Apache-2.0. Native GUI and bundled default fallback fonts. https://github.com/emilk/egui
- **Inter** — Rasmus Andersson, SIL Open Font License 1.1. The font and license are in `assets/fonts`. https://github.com/rsms/inter
- **image** — MIT OR Apache-2.0. Image decoding and processing. https://github.com/image-rs/image
- **arboard** — MIT OR Apache-2.0. Explicit clipboard image import. https://github.com/1Password/arboard
- **rfd** — MIT. Native file dialogs. https://github.com/PolyMeilex/rfd
- **serde / serde_json** — MIT OR Apache-2.0. Local settings. https://github.com/serde-rs/serde
- **directories** — MIT OR Apache-2.0. Platform-specific local storage paths. https://github.com/dirs-dev/directories-rs

Cargo.lock includes all transitive dependencies. Their license texts are supplied in the release's `third-party-licenses` folder. The Rust runtime is MIT/Apache-2.0. No paid services or API keys are used.

- **XCap** — Apache-2.0. Native Windows window capture. https://github.com/nashaofu/xcap
- **tungstenite** — MIT OR Apache-2.0. Local Chrome DevTools WebSocket connection. https://github.com/snapview/tungstenite-rs
- **windows-sys** — MIT OR Apache-2.0. Windows DPI and single-instance integration. https://github.com/microsoft/windows-rs
- **getrandom** — MIT OR Apache-2.0. Operating-system random pairing token. https://github.com/rust-random/getrandom
- **Six classic chess books** — Public domain in the USA. Original Project Gutenberg notices and licenses retained. Source editions and provenance: [docs/BOOKS.md](docs/BOOKS.md), [assets/books/catalog.json](assets/books/catalog.json).
