# Local chess library

Six complete classic texts are included in the executable and the portable package. The library has about 411,000 words. The source editions are listed by Project Gutenberg as public domain in the USA. Their original notices and licenses are retained. Texts were obtained from GITenberg mirrors because the primary download endpoint was temporarily unavailable.

- [Chess Fundamentals](https://www.gutenberg.org/ebooks/33870) — Jose Raul Capablanca; local text `33870.txt`.
- [Chess Strategy](https://www.gutenberg.org/ebooks/5614) — Edward Lasker; local text `5614.txt`.
- [The Blue Book of Chess](https://www.gutenberg.org/ebooks/16377) — Howard Staunton and others; local text `16377.txt`.
- [Chess and Checkers: The Way to Mastership](https://www.gutenberg.org/ebooks/4913) — Edward Lasker; local text `4913.txt`.
- [Chess Generalship, Vol. I](https://www.gutenberg.org/ebooks/55278) — Franklin K. Young; local text `55278.txt`.
- [Chess History and Reminiscences](https://www.gutenberg.org/ebooks/4902) — H. E. Bird; local text `4902.txt`.

Related passages are selected through keyword matching for the move type or position phase. They are quotations about general concepts, not claims that the author analyzed the current game. Stockfish independently calculates moves. These historical editions may use obsolete rules, older opening theory, and descriptive notation.
